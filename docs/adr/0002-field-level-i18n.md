# Field-level translation, Czech added later

The site launches in English only, but the schema is localised per field (each translatable field holds an English and a Czech value) rather than per document (a separate Czech copy of each Event, Section, etc.). We chose field-level because the audience is mostly exchange students, so Czech will lag behind English for a long time: an empty Czech field falls back to the English one, and editors never have to keep two documents in sync or re-link references per language. English lives at the site root and Czech under `/cs/`, with the same slugs in both languages; the EN/CZ switch stays hidden until Czech content is ready. The cost is that every text field carries a second value editors can see, and switching to document-level later would mean migrating all content.
